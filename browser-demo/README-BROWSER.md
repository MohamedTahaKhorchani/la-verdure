# Self-contained browser demo edition

Separate adaptation approved 23 November 2026. Original app UI/assets are retained; state is fictional/sample and saved only in the visitor’s browser. Reset demo restores sample state. No live backend, actual accounts, databases or private runtime data are connected.

Build: `npm run build:browser`. Serve `dist/` with a static web server.

Original catalogue workspace and print-layout generator. Seed products and generated sample illustrations only; local shop photographs and databases are excluded. PNG/JPEG/WebP images are resized client-side. Browser printing/Save as PDF replaces Electron export; no file save is claimed before the user completes the browser dialog. Desktop folder imports/backups are unavailable. Tests: `npm test`.
